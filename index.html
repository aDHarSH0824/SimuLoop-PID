📘 Control Systems Engineering Quick Reference Guide

Continuous & Discrete PID Control Equations

The time-domain continuous control signal \(u(t)\) is defined by:

\[ u(t) = K_p \, e(t) + K_i \int_{0}^{t} e(\tau) \, d\tau + K_d \, \frac{de(t)}{dt} \]

Taking the Laplace Transform yields the transfer function \(G_c(s)\):

\[ G_c(s) = K_p + \frac{K_i}{s} + K_d s = \frac{K_d s^2 + K_p s + K_i}{s} \]
  • Proportional Term (\(K_p\)): Generates control action proportional to current error. Increases bandwidth and speeds up response, but higher values lead to overshoot and instability.
  • Integral Term (\(K_i\)): Accumulates historical error over time. Eliminates steady-state error (\(e_{ss} \to 0\)) for type-1 step responses.
  • Derivative Term (\(K_d\)): Anticipates future error trajectory based on current rate of change. Adds phase lead (damping), suppressing overshoot and stabilizing oscillations.

Ziegler-Nichols Closed-Loop Frequency Response Method

  1. Set \(K_i = 0\) and \(K_d = 0\). Gradually increase \(K_p\) until the system reaches sustained, un-damped oscillation.
  2. Record this gain as the Ultimate Gain (\(K_u\)) and measure the period of oscillation as the Ultimate Period (\(T_u\)).
  3. Calculate PID parameters using the standard tuning table below:
Controller Type \(K_p\) \(K_i\) (or \(T_i\)) \(K_d\) (or \(T_d\))
P Controller \(0.50 \, K_u\) — —
PI Controller \(0.45 \, K_u\) \(1.20 \, K_p / T_u\) —
Classic PID \(0.60 \, K_u\) \(2.00 \, K_p / T_u\) \(K_p \, T_u / 8\)

Practical Control Engineering Solutions

1. Integrator Anti-Windup (Clamping)

When actuator output saturates at maximum supply limits (\(\pm V_{max}\)), large accumulated integral error causes severe overshoot and delayed recovery. Anti-windup clamping halts integral accumulation whenever the control signal is saturated unless the error opposes saturation.

2. Derivative Kick Mitigation

A sudden step change in target setpoint \(r(t)\) produces an instantaneous infinite error derivative \(\frac{de}{dt}\), causing a huge control pulse ("derivative kick"). Computing derivative on measurement (\(-\frac{dy}{dt}\)) removes setpoint step spikes while retaining damping during load disturbances.

3. Low-Pass Derivative Filter

Raw digital differentiation amplifies high-frequency sensor noise. We pass the derivative term through a first-order low-pass filter with time constant \(\tau_f\):

\[ D(s) = \frac{K_d \, s}{1 + \tau_f s} \]

Real-World Focus: Sub-Micron Precision in Morphle Labs RoboTome

In high-throughput automated pathology micro-scanners like Morphle Labs' RoboTome, tissue slide stages require precise sub-micron closed-loop positioning under dynamic physical conditions:

  • Friction & Load Disturbance Rejection: Slide carrier momentum and mechanical stage friction act as external torque disturbances. A well-tuned PID controller rejects disturbance pulses without specimen vibration.
  • High-Resolution Optical Encoder Feedback: Optical scale encoders feed quadrature pulses to the micro-controller loop at up to 1 kHz update rates.
  • Zero Steady-State Error Requirement: Microscopic focal planes require precise zero position error (\(e_{ss} = 0\)) so tissue scans remain perfectly in focus across continuous scanning trajectories.
